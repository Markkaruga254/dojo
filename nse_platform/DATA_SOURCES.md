# Data sources: audit before you build

**Fill the "Verified" columns in Week 1.** Do not scrape anything without reading its Terms of Service and robots.txt. Prefer official feeds and licensed data; never bypass paywalls or logins.

| Source type | Candidates to evaluate | Terms checked? | Method (feed/API/licence) | Notes |
|---|---|---|---|---|
| Prices / market data | NSE website, a licensed data vendor, broker data | | | NSE market data may be licensed; confirm redistribution rights before charging |
| Company announcements | NSE announcements, company IR pages | | | |
| Regulator notices | Capital Markets Authority | | | |
| News | Kenyan business news sites with RSS | | | Use headlines + link out; do not republish full articles |
| Analyst/broker research | Public broker notes | | | Cite, do not copy |
| Social signals | X/Reddit/Telegram | | | API terms; noisy; later phase |

Rules
- Link to originals; store only what you need; respect copyright (short excerpts, your own summaries).
- Record the retrieval time and source URL for every item.
- Rate-limit politely; identify your user agent; back off on errors.
