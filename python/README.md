# Applied Python track

Python that ML, backend and DevOps roles actually test: clean code, tests, HTTP/APIs, data handling, concurrency, scripting for automation, SQL, and the language's sharp edges.

- `CURRICULUM.md`: week-by-week themes, lab specs, and the "must be able to explain" list
- `labs/`: test-backed labs. Starter code raises `NotImplementedError`; make the tests pass.

```bash
make lab LAB=lab01_log_analyzer      # or: cd python/labs/lab01_log_analyzer && pytest -q
```
Rules: read the docstring, write your own extra test first, then implement. No copying from AI: ask for review after tests pass.
