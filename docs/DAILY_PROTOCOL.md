# Daily protocol (weekday, ~10 focused hours)

| Block | Hours | What |
|---|---|---|
| 1. DSA | 2.0 | New problems for the week's topic (≥ 25 min attempt each), then one spaced re-solve |
| 2. Applied Python | 1.5 | The week's Python theme; lab work with tests |
| 3. ML | 3.0 | Hugging Face lesson (≈1h) + implement the mechanism yourself (≈2h) |
| 4. Platform | 2.5 | Weeks 1–8: platform build. Weeks 9–16: see reassignment below |
| 5. Log + review | 1.0 | Fill the log, update tracker, explain one concept, plan tomorrow's top 3 |

Take real breaks: 10 min per hour of deep work, a proper lunch, and stop at a fixed time.

## Reassignment from Week 9 (platform → maintenance only)
- 1h/week max on platform (keep ingest alive, fix bugs)
- Remaining 2.5h/day goes to: +1h DSA (hard-problem exposure, timed sets), +1h Python/SQL assessment practice, +0.5h capstone

## Weekend
- **Saturday:** timed mock (Weeks 4, 6, 8, 10, 12, then weekly) → retro within 24h. Cloud Track prep/teaching fits here.
- **Sunday:** rest, then 45 minutes: `make stats`, log review, pick next week's weak spots.

## When stuck (any track)
1. Restate the problem in your own words. 2. Smallest failing example. 3. 25-minute timer. 4. Write what you tried. 5. Ask for a hint, not the answer. 6. Log it as `hinted`.

## Shutdown ritual
Commit → log filled → tomorrow's top 3 written → close the laptop.
