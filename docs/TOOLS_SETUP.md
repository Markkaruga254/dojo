# Tools setup

- Python 3.10+ (3.12 preferred), `git`, VS Code, Docker Desktop (or Docker Engine).
- Virtual env: `python -m venv .venv && source .venv/bin/activate`
- `pip install -e ".[dev,labs]"` (pytest, ruff, numpy, fastapi, httpx)
- Free GPU: Google Colab or Kaggle notebooks. Keep notebooks small; save outputs to Drive/GitHub.
- Accounts: GitHub, Hugging Face, Kaggle, LeetCode, a Codility practice account.
- Optional later: AWS free tier / GCP free credits for the cloud labs. Set billing alerts first.
