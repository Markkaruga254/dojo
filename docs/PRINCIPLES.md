# Principles

1. **Concepts before implementation.** Understand the mechanism, implement the core yourself, only then use the library.
2. **The ledger is honest.** Every DSA attempt is `independent`, `hinted` (a nudge after ≥25 min), or `assisted` (you saw the solution). Only independent solves count toward gates.
3. **Attempt first, AI second.** Spend 25 minutes of real effort on a problem before asking for a hint, and write what you tried. Use AI to explain, review and test your reasoning, never to produce the answer you then copy.
4. **Spaced repetition.** Any problem that was hinted/assisted/failed is re-solved cold after 3, 7 and 21 days. `forge stats` lists what is due.
5. **Explain it.** Each day, write one concept in the log as if teaching a Cloud Track student. If you cannot, it is not learned.
6. **Gates, not vibes.** See `ROADMAP.md`.
7. **Volume has a ceiling.** Ten focused hours is a lot. Protect DSA and Python first; the platform block flexes. One lighter block and one rest day a week are part of the plan, not rewards.
8. **Ship small, ship often.** Commit daily. A green test is better than a perfect plan.
9. **Honest metrics in public.** If you publish your journey, publish the bad days.
