# Python interview bank: answer aloud, 2 minutes each, then check
1. Mutable default arguments: what goes wrong and the fix?  2. List vs tuple vs set vs dict: complexity and when to use each.  3. How does a dict work internally?  4. Generators vs lists; `yield`; memory behaviour.  5. Decorators: write one with arguments and `functools.wraps`.  6. Closures and late binding in loops.  7. `is` vs `==`; interning.  8. Shallow vs deep copy.  9. `__init__` vs `__new__`; `__repr__` vs `__str__`.  10. Context managers: write one with `contextlib`.  11. The GIL: what it blocks, when threads still help, when to use multiprocessing/asyncio.  12. `asyncio` vs threads for 1,000 HTTP calls.  13. Exceptions: `try/except/else/finally`, custom exceptions, chaining.  14. Dataclasses vs namedtuple vs Pydantic.  15. Type hints: what they do and do not enforce.  16. Iterators vs iterables; implement `__iter__`/`__next__`.  17. Memory management and reference counting; cycles.  18. `*args/**kwargs`; keyword-only args.  19. Sorting stability and `key=`.  20. Virtual environments and dependency pinning.  21. Testing: fixtures, mocks, parametrisation; what makes a test flaky.  22. How would you profile a slow function?  23. Why is `list.pop(0)` slow; what to use?  24. Write a function to flatten nested lists iteratively.
