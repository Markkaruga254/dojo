# System design starter
Framework: clarify requirements and scale → API → data model → high-level components → deep dive on the bottleneck → failure modes → trade-offs.
Practise (30 min each, whiteboard, aloud): URL shortener · rate limiter · news aggregator (your platform!) · notification service · ML inference API with batching · RAG question-answering service · log pipeline.
For each: state assumptions with numbers (QPS, storage), name one thing you would cut for v1.
