# Assessments

This directory turns practice into observable evidence. Use the rubric and record the result, not just the time spent studying.

## Start here

- [`PRACTICAL-ASSESSMENT-PLAYBOOK.md`](PRACTICAL-ASSESSMENT-PLAYBOOK.md) — timed problem workflow, retrospective, readiness gates, integrity rules.
- [`CAPSTONE-RUBRIC.md`](CAPSTONE-RUBRIC.md) — score project quality with evidence and critical-fail rules.
- [`mocks/`](mocks/) — schedule, scoring rubric, and retrospective template.
- [`interview/`](interview/) — question banks for Python, ML, cloud/DevOps, behavioural, and system design practice. Answer aloud and explain trade-offs.

## Rules

- Update `mocks/SCHEDULE.md` only with confirmed dates and formats; verify them from the actual invitation.
- Record the score, duration, independent/hinted/assisted status, root cause, remediation task, and cold re-solve date.
- Never publish confidential live assessment questions or personal/employer information.
- A readiness gate is passed only when its criteria have evidence. Course completion or hours studied do not substitute for performance.
