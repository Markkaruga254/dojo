# Cloud Track teaching plan (GDG on Campus): 10 sessions
Each session: 10 min concept · 30 min live demo · 20 min student lab · 5 min recap. Prepare on Saturdays (≈1h).
1. Linux, Git, GitHub · 2. Containers with Docker · 3. Dockerise a web app · 4. Deploy to a managed container service · 5. CI/CD with GitHub Actions · 6. Infrastructure as code (Terraform intro) · 7. Secrets, IAM, least privilege · 8. Logs, metrics, alerts · 9. Cost awareness and free tiers · 10. Demo day: students deploy their own app.
Make every session reproducible: a repo with a starter, a solution branch, and a checklist. If you cannot explain a step simply, it is a gap in your own learning: log it.
